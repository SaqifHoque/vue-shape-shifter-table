# Minimal vue-shapeshifter-table consumer

This independent Vite app installs `vue-shapeshifter-table@1.1.1` from npm. It imports the published component and CSS, with no aliases to the library source. The component is rendered inside `div#component-container` on a plain white page.

```sh
cd examples/minimal
npm ci
npm run dev
```

Run `npm run build` for the static site. The demo and its dependencies are not included in the library npm archive.
